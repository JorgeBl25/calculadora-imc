# calculadora-imc
Calculo del indice de masa corporal

Esta calculadora dependera unicamente de dos variables las cuales seran el peso y la altura y su uso sera para calcular el indice de masa corporal dejando valores tales que se identifique segun los valores agregados si la persona esta dentro de un rango de peso conforme a su altura o por el contrario excede.

Ingresar datos obtenidos de los pacientes como son Peso (Kg) y estatura (M) y ejecutar el programa. El programa arrojara lo calculado (IMC) en conjunto con un texto que dictaminara si esta en valor normal o desfasado.
